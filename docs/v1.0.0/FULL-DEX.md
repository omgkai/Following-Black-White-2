# Full Dex

Available in **v1.0.0** and later.

Set **FULL DEX** to **ON** in Options, then choose **CONFIRM**. Save your game normally to retain the setting after closing the game. It is OFF by default.

Before the credits, Full Dex merges Black 2 and White 2’s original wild encounters, including version exclusives. Original levels, encounter methods and seasons are retained. Some encounter probabilities change to accommodate both versions.

After the credits, all **649 Pokémon** can be caught. Both editions use the same expanded tables. Legendary and Mythical Pokémon appear as rare wild encounters. Original story encounters, gifts and event flags are unchanged.

Full Dex OFF restores your edition’s original tables. The separate WILD RAND option overrides species when enabled; set it OFF to use this guide. WILD SCALE can change the listed levels.

Seasonal location tables: [Spring](Full-Dex-Spring.csv) · [Summer](Full-Dex-Summer.csv) · [Autumn](Full-Dex-Autumn.csv) · [Winter](Full-Dex-Winter.csv). Each lists all 649 species, areas, map section IDs, encounter methods, chances and level ranges. Probabilities are per encounter of that type.

Required placements use regular land encounters, Surf and Fishing, avoiding frozen marshes and dry-season sewer water. Coverage has been checked from the tables and native loader; Kai confirmed the final build working before publication; platform coverage is not exhaustive.
